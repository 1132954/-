# A 的 v0.5：依日期與類別查詢支出

這次新增「支出條件查詢」，並讓圓餅圖顯示各類別實際金額及總支出。兩者與既有新增、修改、刪除流程共用原本的 CSV。

## 從主選單操作

```bash
python main.py
```

選擇 **5. 查詢支出（日期／類別）**，依序輸入開始日期、結束日期與類別。

| 條件 | 規則 |
| --- | --- |
| 開始日期 | 含當日；留空代表沒有下限 |
| 結束日期 | 含當日；留空代表沒有上限 |
| 類別 | 名稱完全符合；英文忽略大小寫；留空代表全部類別 |
| 多個條件 | 同時符合全部條件（AND） |
| 取消 | 開始日期輸入 `q`；任何欄位輸入 `:q` 也可返回 |

全部留空會顯示所有支出。每次結果包含符合條件的紀錄、筆數與精確金額合計；查完可以繼續下一次查詢。

結果顯示的「原編號」是目前完整 CSV 列表中的支出編號，方便回到修改或刪除功能時對照。新增或刪除之後，請重新查看列表，因為編號可能隨紀錄順序變動。

## 獨立執行

不指定篩選參數會進入互動模式：

```bash
python query_expenses.py
```

指定任一條件會查詢一次並結束：

```bash
python query_expenses.py --data data/sample_expenses.csv --start 2026-11-16 --end 2026-11-17 --category 餐飲
```

範例結果為原編號 **3、6**，共 **2 筆、215.00**。只指定 `--start`、`--end` 或 `--category` 也可以。

日期必須為有效的 `YYYY-MM-DD`，且開始日期不得晚於結束日期。無符合紀錄時顯示 0 筆與 0.00。查詢不會新增、改寫或刪除 CSV；資料檔不存在時也不會建立空檔。

## 模組介面

- `filter_expenses(expenses, start, end, category)`：篩選既有紀錄，回傳 `(原編號, Expense)` 列表。
- `query_file(path, start, end, category)`：讀取 CSV 後查詢。
- `run_query(path)`：主選單使用的互動式查詢入口。

## 圓餅圖的實際金額

主選單選擇 **4. 顯示類別圓餅圖**。每個類別旁會顯示該類別的金額合計，圖上方另顯示所有類別的總支出。

例如固定範例資料會顯示餐飲 300.00、交通 200.00、娛樂 350.00、生活用品 200.00，總支出 1,050.00。顯示使用千分位與兩位小數，直接取 CSV 的 Decimal 合計，不從圖形比例反推金額。

圓餅圖仍統計指定 CSV 的全部紀錄；查詢功能會顯示篩選結果，不會改寫 CSV 或自動改變圓餅圖的統計範圍。
