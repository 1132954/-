# A 的 v0.3：修改既有支出

此功能沿用儲存庫既有的修改支出實作，另外補上原檔保護、選取後資料變更檢查、獨立執行方式與測試。

執行 `python main.py`，選擇 **2. 修改既有支出**。也可以執行：

```bash
python input_module.py --edit
```

1. 依列表的編號選取一筆支出；`q` 返回。
2. 日期、金額、類別直接 Enter 會保留原值。
3. 備註 Enter 保留原值，輸入 `-` 清空。
4. 所有欄位通過檢查後才儲存；可以繼續修改其他筆，或 `q` 返回。

此功能只更新指定的那一筆，其他資料維持原順序。先寫同目錄暫存檔再替換原檔；寫入或替換失敗時不會先清空原始 CSV。選取後若資料已被其他操作變更，會要求重新選取。

## 測試

```bash
python -m unittest discover -s tests -v
```

測試使用暫存資料，不會修改個人記帳檔。

## 版本與分支

本版對應原先規劃的 A v0.2 修改支出功能，依目前開發順序標記為 v0.3。功能邏輯與先前準備的 v0.2 套件相同；本次僅更新版本標示及說明。

本功能分支可與 main 整合；合併時保留 merge commit，方便在 Network Graph 查看協作紀錄。
